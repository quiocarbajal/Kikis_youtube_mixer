# Project Rules & Guidelines

## Commit Messages & Program Terminology
- All commit messages MUST be written strictly in English.
- Always cite all program parts, components, UI controls, filters, variables, and features using their English version and naming (e.g., "Live Versions", "Remix / Remaster", "All", "Surprise Me", "Blacklist", "Liked Songs"), regardless of the language used during conversation or discussion.

## Git & Version Control Protocol
- NEVER execute `git commit` or `git push` autonomously.
- Always present a clear summary of changes and the proposed commit message to the user, and wait for their explicit approval before committing or pushing.
- The user performs manual testing on top of automated test suite verification before committing.
